# 邮箱演练连接

GET /mailbox 返回邮箱世代和 UID/原文地址；?epoch=2 切换世代且复用 UID。GET /mail/1 返回多部分 EML，/mail/2 返回未知字符集样本，/mail/new1 是同 Message-ID 不同正文。每次运行使用配置的 mailbox 与 Corpus Gate source；来源许可由业务模块管理。允许附件类型首版为 text/plain、text/html、text/csv；图片只记录忽略原因。

运行 python demo_support/source.py --port 8787 可启动回环来源；运行 python demo_support/check.py 检查样本和故障开关。来源仅产生输入，不调用业务导入。
