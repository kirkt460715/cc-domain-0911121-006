# 邮箱演练连接

GET /mailbox 返回邮箱世代和 UID/原文地址；?epoch=2 切换世代且复用 UID。GET /mail/1 返回多部分 EML（multipart/mixed 内含 multipart/alternative 与文本附件），/mail/2 返回未知字符集样本，/mail/new1 是同 Message-ID 不同正文，/mail/3 是签名图片加坏附件的部分失败样本，/mail/4 是转发重复件。每次运行使用配置的 mailbox 与 Corpus Gate source；来源许可由业务模块管理。允许附件类型首版为 text/plain、text/html、text/csv；图片只记录忽略原因。

运行 python demo_support/source.py --port 8787 可启动回环来源；运行 python demo_support/check.py 会启动回环来源并驱动完整业务演练：来源授权、邮件同步、部分失败留痕、转发去重、同号冲突、同 UID 新世代、中断续跑、失败部分更正重试、来源撤回后停止导入以及文档溯源。来源仅产生输入，业务导入由 corpus_gate.mail 连接器完成。

连接器的留痕规则：

- 投递证据（mailbox_epoch、uid、EML 摘要、MIME 路径、部件状态与错误）与文档身份分表保存；去重键是 mailbox 加 epoch 加 UID，Message-ID 与 Subject 都不作去重键。
- multipart/alternative 优先取纯文本，缺失时退回 HTML 并转成纯文本；字符集按 MIME 声明严格解码，传输编码由标准库还原，未声明字符集时先试 UTF-8 再退 Latin-1，不做静默替换。
- 图片等非文本部件只登记 ignored 及原因；允许类型之外的附件同样忽略并留痕；无法解码的附件标记 failed，同封邮件的正常正文仍会入库，整封投递记为 partial。
- 正文与附件沿用既有文档去重、质量检查与审查流水线；转发重复在文档层收敛为同一份资料，但每封邮件的部件行都保留，可按文档反查全部来源邮件与 MIME 部件。
- 失败部件可用更正文本重试，重试只重建该封投递的部件证据并新开批次，内容相同的重试在文档层记为 duplicate，不会建出多份资料。
